# ld-define-ticket

Usá el skill `ld-define-ticket` para definir el ticket: investiga, pregunta hasta
que no queden decisiones abiertas y crea o actualiza el issue.

**Argumentos:** vacío → ticket nuevo · `#N` o URL → ticket existente ·
`--quick` → captura rápida, sin investigación y con el ticket en "Falta Definición".

**Announce at start:** "Usando ld-define-ticket — definiendo el ticket."
